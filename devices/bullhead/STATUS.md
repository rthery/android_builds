# Nexus 5X status

Last updated: 2026-10-18. Results are based on manual device testing unless stated otherwise.

| Feature | Status |
| --- | --- |
| Boot and USB debugging | Working |
| Wi-Fi | Reconnect, DHCP, routing, DNS and internet validation passed |
| Mobile network | SIM, SMS and LTE data working |
| Voice calls | Incoming and outgoing calls with two-way audio working |
| Camera | Photos, camera switching and short video recording/playback with sound passed; extended stability testing remains |
| Fingerprint | Unlock working |
| Display | Automatic brightness, auto-rotate and Extra Dim working |
| Bluetooth | Adapter startup and phone pairing tested; headphone audio and hands-free calls remain untested |
| GPS | Assistance data downloads and injection work; positioning remains unresolved |
| Traffic accounting | Unsupported |
| NFC | Enabled; tag reading remains untested |
| Hardware codecs | Eight automated encode/decode roundtrips passed |
| SELinux | Permissive |
| Encryption | Encryption checks do not pass; support remains unresolved |
| IMS video calling | Untested |
