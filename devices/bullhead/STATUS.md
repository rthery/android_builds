# Nexus 5X status

Last updated: 2026-10-21. Results are based on manual device testing of /e/OS 4.4 unless stated otherwise.

| Feature | Status |
| --- | --- |
| Boot and USB debugging | Working |
| Updates | Settings > Updater installs a signed full update through the /e/OS recovery, keeping user data |
| SELinux | Enforcing |
| Encryption | File-based encryption (AES-256), unlocked with PIN or fingerprint |
| Wi-Fi | Connection, routing, DNS and internet validation working |
| Fingerprint | Enrolment and unlock working |
| Sensors | All 25 sensors reporting |
| Bluetooth | Adapter working; headphone audio and hands-free calls not yet tested |
| Play Integrity | Basic integrity passes with microG and a Google account; device integrity is not possible on this hardware |
| Mobile network | SIM, SMS and LTE data not yet tested |
| Voice calls | Not yet tested |
| Camera | Not yet tested |
| Display | Automatic brightness, auto-rotate and Extra Dim not yet tested |
| GPS | Not yet tested |
| Hardware codecs | Not yet tested |
| NFC | Enabled; tag reading not yet tested |
| IMS video calling | Not yet tested |
| Traffic accounting | Unsupported |
